# SILVA

Компактний процедурний хвойний ліс на Three.js. Усі природні об’єкти та текстура кори створюються алгоритмічно — зовнішніх 3D-моделей немає.

## Запуск

```sh
npm install
npm run dev
```

Відкрийте адресу, яку виведе Vite. Production-збірка: `npm run build`; локальний перегляд збірки: `npm run preview`.

## Керування

- Перетягування — обертання камери навколо галявини.
- Коліщатко / жест двома пальцями — наближення.
- Ранок, Туман, Сутінки — атмосфера.
- Інший ліс — новий відтворюваний seed.
- Кнопка звуку — синтезований вітер і птахи (початково вимкнено).
- H або кнопка розгортання — приховати / повернути інтерфейс.

## Графіка

Рельєф із багатомасштабним шумом, звивиста стежка, сосни з коренями та ярусами гілок, хвоя, трава, папороті, замшілі камені, повалений стовбур, гриби, пилок. InstancedMesh використовується для повторюваної геометрії. Вітер анімовано у vertex shader; карта тіней статична, щоб не перемальовувати ліс щокадру. Об’ємне сонячне світло розраховується окремим проходом із 24 кроків у половинній роздільності через карту глибини та карту тіней; відновлення світла враховує глибину сцени. Фінальний прохід додає атмосферну перспективу, ACES tone mapping, віньєтку й легкий grain.

Потрібні сучасний браузер із WebGL2 та GPU. Google Fonts — необов’язковий мережевий ресурс, для шрифтів є системні резервні варіанти. `prefers-reduced-motion` вимикає рух рослин і пилку.

## Прогулянка від першої особи

Натисніть «Увійти в ліс», щоб захопити мишу й почати прогулянку:

- WASD або стрілки — переміщення; миша — огляд.
- Shift — біг; Space — стрибок.
- Esc — пауза та звільнення курсора. «Продовжити прогулянку» повертає керування з того самого місця.
- «Повернутися до огляду» — попередня орбітальна камера.

Гравець рухається по рельєфу; стовбури, великі камені й повалене дерево мають наближені горизонтальні колайдери. Стрибок декоративний: він не дозволяє перестрибувати ці колайдери. Межі прогулянки утримують гравця всередині лісу. Генерація нового лісу повертає гравця на стежку. Після втрати фокусу прогулянка автоматично призупиняється. Цей режим потребує клавіатури, миші та браузера з підтримкою Pointer Lock; на сенсорних пристроях залишається орбітальний огляд.

## Якість і FPS

Меню у правому верхньому куті: «Авто» підлаштовує роздільність під швидкодію, «Максимальна якість» зберігає підвищену роздільність на HiDPI, «Більше FPS» знижує її для швидшого рендерингу. Лічильник показує фактичний FPS після короткого прогріву. Повноекранне FXAA згладжує краї. Рослинність розбита на просторові групи, які відсікаються поза полем зору. Вимірювання в локальному headless Edge на 1440×960: приблизно 82 FPS до оптимізації та 106 FPS після; на іншому GPU або ракурсі результат відрізнятиметься.

## Біоми

Початкова сцена — джунглі. Меню «Біом» перемикає джунглі та хвойний ліс. Джунглі мають окремий генератор широколистих дерев, пальм, ліан, великих листків підліску й помаранчевих квітів, а також зеленішу вологу атмосферу. Обидва біоми підтримують прогулянку, зіткнення, регенерацію та режими якості. Зміна біому повертає гравця на безпечну точку стежки; для продовження прогулянки потрібно знову захопити мишу.

## Збирання ресурсів

У режимі прогулянки наблизьтеся до гриба, невеликого каменя або гілки й поверніться в його бік. Кільце та підказка показують доступний ресурс; E збирає один предмет, I ховає або повертає наплічник. Збирання доступне на відстані до 2,5 метра, коли гра активна, і блокується великими перешкодами. Великі камені та живі дерева не добуваються.

Гриби зникають разом із ніжкою, камінці й гілки також прибираються зі сцени. Кількості та зібрані об’єкти зберігаються в localStorage цього браузера й адреси. Повернення до того самого біому та seed не відновлює зібрані предмети; новий seed створює нові ресурси. Якщо браузер забороняє localStorage, інвентар працює лише до перезавантаження сторінки.

## Чіткість і стабільність руху

Для ранку й сутінок туман суттєво зменшено; перші 14 метрів не затуманюються. Ранкове небо має чисту блакитну палітру. Близьке тропічне листя має процедурні прожилки, тоді як високі крони використовують легшу геометрію. Автоматична зміна роздільності відбувається лише поза активною прогулянкою. Фізика перевіряє найближчі перешкоди, а пошук ресурсів працює з обмеженою частотою без постійного перезаписування підказок. Шейдери готуються до початку прогулянки. Конкретна плавність залежить від GPU, роздільності та браузера.

## Стежки між біомами та наплічник

Ходьбу зменшено з 4,2 до 3,5 м/с, біг — із 7,5 до 6,2 м/с. У наплічнику є локальні SVG-ілюстрації грибів, каміння й гілок.

Щоб змінити біом без меню, ідіть стежкою до вказівника на одному з її кінців. Перехід автоматичний і працює в обидва боки: коротке затемнення приховує генерацію наступної ділянки, після чого прогулянка продовжується з протилежного кінця стежки. Захоплення миші, напрямок погляду, seed та інвентар зберігаються. Якщо натиснути Esc, керування залишається на паузі. Зібрані предмети не відновлюються при поверненні.

Це послідовне завантаження ділянок, а не одночасне відображення двох повних біомів. Якість моделей і налаштування рендерингу не знижуються. Під час самого переходу можлива коротка пауза генерації; її тривалість залежить від пристрою.
