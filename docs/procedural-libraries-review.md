## Фактичний тест

Ізольована папка `tmp/procgen-review`; основний package.json і код гри не змінені. Пакети встановлено з вимкненими install scripts. Headless Microsoft Edge, Three.js revision 180, WebGL.

- EZ-Tree / Oak Small: 3206 трикутників гілок + 3600 трикутників листя = 6806; генерація близько 14 мс в одному запуску.
- THREE.Terrain: створений і відрендерений рельєф на 1024 вершини та об’єкт трави.
- simplex-noise: 1000 скінченних значень 2D шуму.
- Помилок JavaScript або шейдерів не зафіксовано.
- У npm EZ-Tree 1.1.0 методи generateLODs і createGeometry відсутні, хоча README поточного GitHub main їх описує. Для них треба окремо перевірити й зафіксувати конкретний commit або реалізувати спрощення локально.

Результат є smoke test сумісності, а не виміром FPS повного біому, оцінкою художньої якості чи перевіркою всіх пресетів і текстур. Показники C++ із README FastNoiseLite не є показниками нашого JavaScript.

## Практичний порядок

1. Окремий тестовий гай EZ-Tree: 4–8 варіантів дерев, просторове відсікання, бюджет трикутників і спрощення дальніх дерев.
2. Порівняти кадри й час кадру з поточним лісом на однаковій камері та пристрої.
3. Залишити керування, інвентар і переходи. Міняти лише генератор дерев та пов’язані колайдери.
4. Потім окремо оцінити THREE.Terrain для гірської долини; не міняти одночасно дерева, поверхню і весь renderer.
